# Mil Focos — milfocos.com

Un mazo, veinte juegos. Sitio estático servido con GitHub Pages.

- `index.html` — portada e índice de juegos
- `catalogo.html` — reglas completas de los 20 juegos
- `Un_mazo_20_juegos.pdf` — catálogo en PDF (24 páginas A4)
- `CNAME` — dominio personalizado (no borrar)
- `fonts/` — Bricolage Grotesque (licencia OFL) servida localmente, sin dependencia de Google Fonts
